Courier Management System
Project Description
This project is a web-based courier management system designed for courier businesses in Pakistan. It provides a complete solution for managing orders, tracking shipments, printing documents, and generating reports.

Built With
HTML5

CSS3

JavaScript

Firebase Realtime Database

Key Features
Create and manage courier orders

Auto-generate tracking numbers

Real-time order tracking

Print Air Waybills (3 per page)

Generate load sheets

Import orders from Shopify CSV

Bulk import from CSV files

Dashboard with analytics

Export reports to CSV and Excel

Password protected Firebase settings

Shipper auto-fill on order creation

How to Use
Open the application in any web browser

Login with default credentials (admin / 123)

Configure Firebase in the protected settings tab

Save company information in Settings

Start creating orders

Default Credentials
Portal Login: admin / 123

Firebase Config: password 123

Purpose
This system helps courier companies manage their daily operations digitally. It eliminates paper records and spreadsheets by providing a single platform for booking, tracking, printing, and reporting.
